Optionalscreen

screen?: {
    maxWidth?: number;
    minWidth?: number;
}

Whether to limit the test to only run on specific screen sizes. Will add a resize listener to the page, and run the reset and apply functions if the page falls outside/inside the given bounds.

One or both of minWidth and maxWidth can be provided

Type declaration

  • OptionalmaxWidth?: number

    The maximum screen width to apply the test. Screens larger than this will be excluded

  • OptionalminWidth?: number

    The minimum screen width to apply the test. Screens smaller than this will be excluded

Example

// This will only run on screens between 601px and 1023px
  screen: {
  minWidth: 601,
  maxWidth: 1023
  }

  // This will run on any screen smaller than 767px
  screen: {
  maxWidth: 767
  }
